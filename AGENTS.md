# Project: Turkish Customer Feedback Intelligence

## Project Goal
Build a small, measurable Turkish NLP application that analyzes customer feedback uploaded as CSV files.

The planned application includes:
- Sentiment classification
- Topic/theme analysis
- Relevant feedback retrieval
- Evidence-backed reports referencing source comments
- FastAPI, PostgreSQL, Docker, and automated tests

## Developer Background
The developer has experience with Python, PyTorch, Hugging Face, LoRA/QLoRA, RAG, FastAPI, and Docker.

The developer wants to improve SQL, systematic testing, retrieval evaluation, and production-oriented ML engineering.

## Working Rules
1. Work incrementally. Do not implement the whole project at once.
2. Before substantial changes, explain the plan and wait for approval.
3. Explain the purpose of new files, commands, and important code sections in Turkish.
4. Help the developer understand and write core ML and evaluation code.
5. Prefer simple, maintainable solutions over unnecessary complexity.
6. Add meaningful tests for implemented functionality.
7. Run relevant tests when possible and report actual results.
8. Never invent benchmark scores or claim improvements without evidence.
9. Prevent train/validation/test leakage and document the data split.
10. Verify dataset licensing and provenance before using or distributing data.
11. Never use proprietary employer code, documents, datasets, or model artifacts.
12. Keep API, database, and ML components modular.
13. Document assumptions, limitations, and technical decisions.
14. At the end of each milestone, summarize files changed, tests run, and remaining tasks.

## Initial Scope
Start with repository structure, environment setup, dataset licensing, and exploratory data analysis.

Do not implement model training, APIs, databases, or user interfaces until the relevant milestone is approved.
